# 📅 Day 01 - Introduction & Data Formatting

## 📖 What is Microsoft Excel?

Microsoft Excel is a spreadsheet software used to organize, analyze, calculate, and visualize data. It is widely used in Data Analytics, Finance, Business Intelligence, and Reporting.

- Worksheet

- Status Bar
