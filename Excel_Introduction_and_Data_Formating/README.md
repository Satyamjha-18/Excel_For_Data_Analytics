# 📅 Day 11 - XLOOKUP

## 📖 What is XLOOKUP?

XLOOKUP is a modern Excel lookup function used to search for a value in a range and return the corresponding value from another range.

---

- Lookup Value
- Lookup Array
- Return Array

- Not Found Message
- Horizontal and Vertical Lookup
- Practical XLOOKUP Examples
